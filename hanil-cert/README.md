# 기능장 자격증 취합·판별 시스템 (PHP + MySQL)

기존에 만들어두신 Firebase 기반 "기능장 자격증 취합·판별 시스템"의 배점표·판별 로직·화면 디자인을
그대로 이식하고, 백엔드를 PHP + MySQL로 교체해 학교 서버(가비아 등)에서 직접 운영할 수 있게 만들었습니다.
지난번 만들어드린 자격증 취합 시스템의 IP 제한·세션 보안·CSRF 방어 구조도 그대로 적용했습니다.

## 원본과 동일하게 유지한 부분
- 배점표(CERT_ITEMS/TRACKING_ITEMS/COMPETITION_ITEMS)와 판별 규정 — `includes/scoring.php`
  - 환산점수 35점 이상 + 보유 6종 이상 + 필수 2종(컴활2급·전산회계2급) 보유 시 기능장 대상
  - 전국기능경기대회 참가 시 자동 선발, 경남기능경기대회 4위 이내는 필수 2종 면제
  - 1급/2급 등 상하위 급수 중복 보유 시 상위 급수만 인정 (TIER_PAIRS)
  - IT+ 레벨별, ERP 2급 모듈별은 종수 계산 시 1종으로만 인정 (typeGroup)
- 네이비·골드 색상의 화면 디자인, 점수 배너, 상태뱃지, 학급별 카드 UI — `assets/style.css`
- 학교 공식 "기능장 대상자" 점수합계표 / "자격증 취득 현황표" 엑셀 양식의 컬럼 구성 그대로 재현
- 학생 자가입력 → 담임 확인/승인/반려 → 관리자 전교 취합 워크플로우

## 원본과 달라진(보안 강화) 부분
- Firebase → **PHP + MySQL** (학교 서버에서 직접 운영, 외부 클라우드 의존 없음)
- 담임/관리자 "공통 비밀번호" 대신 **개별 계정 로그인**으로 변경 (관리자가 발급, 유출 시 개별 차단 가능)
- **학교 지정 IP에서만 접속 가능** (관리자 화면에서 IP 추가/삭제 가능, 이중 방어)
- 로그인 5회 실패 시 15분 계정 잠금, CSRF 토큰, 세션 하이재킹 방지, SQL Injection 전면 차단(PDO Prepared Statement)
- xlsx 대신 "HTML표 기반 .xls" 방식으로 엑셀 내보내기 (서버에 별도 라이브러리 설치 없이 병합 셀까지 지원, 더블클릭하면 엑셀에서 바로 열림)

## 폴더 구조
```
hanil-cert/
├── config/          DB 접속정보 · IP 허용목록 · 배점 기준(MIN_SCORE/MIN_TYPES)
├── includes/         security.php(보안) · scoring.php(배점표/판별 로직) · export.php(엑셀) · functions.php
├── student/           학생 화면 (자격증 입력 · 실시간 점수 배너 · 제출/취소)
├── teacher/            담임 화면 (승인·반려 · 점수합계표/현황표 다운로드 · 인쇄)
├── admin/               관리자 화면 (계정관리 · 담임배정 · 명단업로드 · 학기설정 · IP관리)
├── sql/schema.sql      DB 테이블 생성 스크립트
├── login.php            통합 로그인 (학생/담임/관리자 탭, 학생 자가입회)
└── setup.php             최초 1회 관리자 계정 생성용 (사용 후 반드시 삭제)
```

## 설치 순서
1. **DB 생성**: `sql/schema.sql`을 phpMyAdmin에서 실행 (테이블 + 최초 취합주기 1개 자동 생성)
2. **파일 업로드**: `hanil-cert` 폴더를 서버에 업로드 (예: `commerce.knowee.co.kr/hanil-cert`)
3. **config/config.php 수정**: DB 접속정보, `BASE_URL`, 학교 공인 IP(`SCHOOL_FIXED_IPS`)
4. **setup.php 접속** → 관리자 계정 생성 → **즉시 파일 삭제**
5. **관리자 로그인** → [계정 관리]에서 담임교사 계정 발급 → [담임 배정]에서 학년-반에 배정
6. (선택) [명단 관리]에서 전교 학생 명단 CSV 업로드 → 학생 자가입회 시 이름 대조 + 미가입자 파악에 사용
7. [학기 설정]에서 제출 마감일 설정

## 사용 흐름
1. **학생**: `학년/반/번호`로 회원가입(비밀번호 설정) → 로그인 → 항목 체크/개수 입력 시마다 실시간으로 점수·종수·대상여부 갱신 → 재학중 취득 확인 체크 → 담임에게 제출
2. **담임**: 학생 목록에서 클릭 → 상세 화면에서 나이스 대조 후 승인/반려(사유 입력) → 반 전체 "점수합계표"/"현황표" 엑셀 다운로드, 선택 학생 인쇄
3. **관리자**: 전교 현황·미가입자·기능장 대상자 명단 확인, 학기 전환(매학기 새로 시작해도 이전 학기 데이터는 보존됨), IP 관리

CSV/엑셀 컬럼이 학교 최신 공식 서식과 다르면 `includes/scoring.php`의 `template_columns()` / `survey_columns()`만 수정하면 전체 반영됩니다.
